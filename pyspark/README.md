# Apache Spark Implementation

This folder contains the Apache Spark implementation developed for the IST3134 Big Data Analytics assignment.

## Environment
- Amazon EMR
- Apache Spark 3.5
- Amazon S3
- EMR Studio

## Dataset
Video Game Market Price and Revenue Dataset

https://www.kaggle.com/datasets/amithnair/video-game-market-price-and-revenue-dataset

## Analysis Performed

- Data preprocessing
- Revenue by Genre
- Revenue by Platform
- Average Price by Genre
- Genre-Platform Summary Table
